| | |

## Steps

1. `package.json` scripts:
   - `check:fast`: `npm run typecheck && vitest run`;
   - `check:area`: `vite-node tools/scenarios.ts -- --area` (add `--area <a>`
     to `tools/scenarios.ts`: run only scenarios tagged with that area);
   - `check:full`: what `verify` does today, plus `--slow` scenarios;
   - `verify` becomes an alias of `check:full`.
2. In `AGENTS.md` "Verifying your work", add the levels table of
   `docs/m16/README.md` §5 and the sentence "Do not run the full level or
   cohorts unless your phase card asks for it".

## Done when

The scripts exist; `check:fast` < 2 min; each `check:area` < 5 min (record the
times in `docs/m16/timings.md` next to those of 1.1).

## Watch out

PowerShell: `npm.cmd run check:area -- world`; check the echoed command.
Tooling only: no version bump.
