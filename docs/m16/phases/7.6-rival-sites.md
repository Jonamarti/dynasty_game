## Goal

Owner: when another band starts a building, the only option is to help build
it; it should also be possible to attack it to destroy it, and to steal the
materials carried to the site.

## Background

Sabotage exists (M10, `sabotage` verb; `Building.damage` is shared with it;
O5 in `next-steps.md`). Theft exists (`steal`). Check whether either already
accepts an **unfinished** site as a target.

## Steps

1. Menu on a rival band's unfinished site: "Wreck the site" (reuses
   `sabotage`, which for an unfinished site lowers `progress` and scatters
   part of `delivered`) and "Take the materials" (reuses `steal`, moving items
   from `site.delivered`).
2. Consequences exactly as today's sabotage/theft (witnesses, grudges,
   norms) — no new justice rules.
3. NPCs: with the switch on, `strike first` (7.3) and need raids may target a
   rival's site; weight from 7.3.
4. Refusals with reasons (R6).

## Tests

The player wrecks a rival site (progress falls, materials scatter) and steals
from another (items move, the theft is witnessed if someone sees it); e2e of
the menu (add to `scripts.e2e`).

## Done when

Tests pass; R13 holds.
