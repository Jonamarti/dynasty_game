## Goal

Rain, sun, clouds, storm, hail, each with effects on people (cold, wetness,
damage), crops, bushes and buildings; rain or hail on earth (not rock) makes
mud — a building resource away from rivers and lakes.

## Steps

1. Weather state per comarca, deterministic, from **derived seeds** like the
   temperature anomaly (no fork, no `Math.random`): a weather type per time
   point, consistent with the temperature anomaly (cloud and rain lower the
   daily amplitude; clear sky widens it).
2. Effects, one by one, each with its counter, each in its own commit if large:
   - rain: wetness on people outside (reuse the existing wetness/swimming
     state if any); crops get water; outdoor fires may go out;
   - storm: as rain, stronger; building wear ×2 (14.8 parameter);
   - hail: damage to people outside (small), crops, bushes, building wear ×3;
   - sun/clouds: modulate daily amplitude only.
3. Mud: sustained rain on soil tiles (grass, forest, hills — not rock, sand)
   creates temporary mud deposits that dry after N dry days.
4. UI: current weather icon and a line in the HUD (through `t()`).
5. Renderer: a weather layer in its own method of `Renderer.ts` (rain streaks,
   hail), R10 if any overlay.

## Tests

Same seed same weather; hail damages a crop and a building; sustained rain
creates mud only on soil; a checkpoint saved before this phase (no `weather`
key) loads and advances exactly as before (R23 test).
