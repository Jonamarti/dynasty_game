# M16 3.1 — In "You direct", needs warn and do not interrupt

## Goal

When the player directs a character by hand (`sim.autonomy === 'manual'`),
hunger, thirst, cold and tiredness never stop an order. They warn, in three
levels. Physical impediments (hands full, resource gone, target gone, ground
giving way) still stop it. Consequences are unchanged: you can die of thirst
while chopping — that is what the critical level is for.

## Files

`ai/Autonomy.ts`, `systems/ActionSystem.ts` (`interruption`, `pressedByNeed`,
`workLimit`), `core/Simulation.ts` (`autonomy`), `ui/Hud.ts`, `main.ts`
(`reportInterruptions`), `src/style.css`.

## Steps

1. Pass to the `ActionSystem` context a flag `directControl`: true only for the
   player person and only if `sim.autonomy === 'manual'`.
2. In `interruption()`: if `directControl`, return no **need** reason (thirst,
   hunger, cold, fatigue). Keep all the others.
3. In the "is it sensible to start?" checks (`pressedByNeed`), same: with
   `directControl`, never refuse for a need.
4. Warnings, three levels per need, computed with the lines the game already uses:

| Level | When | Text (EN / ES) |
|---|---|---|
| warning | need passes the work line (`workLimit`) | "Hungry" / «Tiene hambre» |
| serious | passes the danger line in `Autonomy.ts` | "Very hungry" / «Tiene mucha hambre» |
| critical | health is falling because of that need | "Starving" / «Se está muriendo de hambre» |

   Same three for thirst, cold, tiredness (whole sentences, R7).
5. Show them in a strip of their own **below** the top bar (B19: no room in
   the bar). Each appears once per level and stays while the level lasts.
   The strip is not an overlay; if you make it one, R10.
6. Do not change "Keeps itself alive" or "Acts alone".
