## Goal

A checkbox "Show all ancestors" in the family view; with it, the tree shows
every known ancestor and scrolls.

## Files

`ui/FamilyTree.ts` (and the mobile zoom of M15 phase 31:
`docs/m15_familytree_mobile_zoom.md`), `social/Knowledge.ts` (R8: only
ancestors the viewer knows of).

## Steps

1. Add the checkbox (label through `t()`), state saved with the UI settings.
2. With it on, walk parents recursively (cycle-safe), only through what
   `Knowledge.ts` allows the viewer to know.
3. The container scrolls (keep R10 if it is an overlay).

## Tests

Unit/e2e: a four-generation tree shows all ancestors with the box checked and
not without; a stranger's ancestors are not revealed.
