## Goal

Each person remembers how much they suffered in each season, for years.
Nothing decides on it yet.

## Background

- `Person.chronic` already accumulates chronic pressure per drive and is used
  by camp relocation (`BandSystem.considerRelocation`). Build on it; do not
  create a second hardship memory.
- **Do not use `Beliefs`**: it holds 48 entries (`ai/Beliefs.ts`,
  `BELIEF_CAPACITY = 48`) and evicts the weakest; this would push out food and
  yield beliefs already in use.
- Inheritance: `systems/LifeSystem.ts` calls `beliefs.inherit(0.6, …)` at birth.

## Files

New `src/sim/ai/Lessons.ts`; `entities/Person.ts`; `systems/LifeSystem.ts`;
`persistence/EntityRecords.ts`; `core/Config.ts` (switch + migration);
`persistence/CheckpointRecords.ts` (migration); `ui/` inspector.

## Steps

1. Add `motivation.foresight: false` to `Config` and a checkpoint migration
   (R23) modelled on `otherBandThinkInterval` (`CheckpointRecords.ts` ~l. 71).
   Test: a checkpoint without the key loads and advances identically.
2. `Lessons` class with `hardship[drive][season] = { level: 0..1, years: number }`
   for drives `hunger`, `thirst`, `warmth`, `safety`.
3. Daily: add `person.chronic[drive]` (normalised 0–1 the way `chronic` is
   already read) into a per-season accumulator.
4. On season change: `mean = accumulator / days`;
   `level = level + (mean − level) × 0.5`; `years += 1`; accumulator = 0.
5. `person.lessons = new Lessons()`; register in `EntityRecords`
   (`constructorEntries`) (R11).
6. Inheritance: where `beliefs.inherit(0.6, …)` is called, children get the
   parents' mean levels × 0.5, with `years = 0`.
7. Recording runs **whether the switch is on or not** (it decides nothing);
   only readers in later phases check the switch. Confirm with
   `switches-off.test.ts` that the fingerprint is unchanged — if the new field
   enters the checkpoint, the fingerprint changes: then re-pin **once** here
   and write "fingerprint changes because a new saved field exists; behaviour
   identical" in the commit, with a test that behaviour (positions, needs,
   actions) is identical to the pre-change build over 3,000 steps.
8. Inspector: show the directed character's own hardships (R8: own, or of
   someone known well).

## Tests

- After a winter with high chronic cold, `hardship.warmth.winter.level > 0`.
- A child is born with half its parents' level, `years = 0`.
- Save/load round trip.

## Done when

Tests pass; R13 holds (behaviour identical).
