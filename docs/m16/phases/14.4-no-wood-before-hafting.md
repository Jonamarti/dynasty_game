## Goal

Owner: "Before hafting is invented, buildings and tools must not use wood:
you cannot fell a tree with bare hands, you need an axe." Sticks (gathered)
are fine; **wood** (felled timber) needs a hafted axe.

## Background (checked on 0.15.160)

- `mud_hut` needs `wood: 8` and `requiresTech: null` — wood from the start.
- `Brain` scores `chop`, and has an `AXE_TOOLS` notion (`Brain.ts` ~l. 404–408,
  3614–3642: `needsAxe`). Whether `ActionSystem.doChop` (~l. 2627) **refuses**
  felling without an axe is not confirmed — check.
- 15 entries in `Building.ts`/`Recipe.ts` mention `wood:`.

## Steps

1. Test `m16-no-wood-before-hafting`: walk `BUILDINGS` and `RECIPES`; for every
   design/recipe whose technology requirements do **not** include `hafting`
   (directly or transitively through `TECHS[..].requires`), assert its
   materials do not include `wood`. List violators by name.
2. For each violator: remove the wood (replace with sticks where it is a frame)
   **or** add the right `requiresTech` if the thing really needs timber
   (carpentry-era items). Write each decision in the diary with a one-line
   historical reason. `mud_hut` is handled in 14.6 — here just make the test
   list it, then skip it with a comment pointing to 14.6, or do 14.6's
   material change here if simpler (say which).
3. Felling: test that a person without an axe cannot fell a tree (`chop` for
   wood) and gets a visible reason ("You need an axe to fell a tree"); with an
   axe they can. If `doChop` already refuses, R22.
4. Make sure gathering **sticks** never needs an axe.

## Tests

The two tests above; `techs-have-effects` and `every-design-has-a-proposer`
(if it exists yet) still pass.

## Done when

No pre-hafting design uses wood; felling needs an axe; re-pinned.

## Watch out

The early economy changes: run `band` and `craft` and report `chop`,
`gather sticks` counters and built shelters before/after. If no band can
build any shelter any more, R0 — do not add wood back silently.
