## Background (checked on 0.15.160)

`entities/Animal.ts` ~l. 246: `get alarmed(): boolean { return
this.alarmedUntil > 0; }`. `ActionSystem` sets `alarmedUntil = ctx.tick + 90`
(~l. 3375, 3408) and only one path resets it to 0 (~l. 3385). So once alarmed,
an animal shows the sign forever.

## Steps

1. `grep -rn "\.alarmed\b" src` and list every reader (renderer and sim).
2. Test: alarm an animal at tick T; at T+91 `alarmed` is false.
3. Make the check time-aware. The getter has no clock: either pass the tick
   (`isAlarmed(tick)`) to every reader, or clear `alarmedUntil` when it
   expires in the wildlife update. Prefer the explicit `isAlarmed(tick)`.
4. If a simulation decision reads it, this changes worlds: re-pin and say so.

## Done when

The test passes; the sign disappears in a manual check after ~90 ticks.
