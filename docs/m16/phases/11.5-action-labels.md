# M16 11.5 — Every action says what it is doing, in both languages (N35, K5, D-19)

| | |

| Changes the world | no (presentation) |

## Goal

The label over a character names the action **and its target**: «cavando
barro», «recogiendo grosellas», «construyendo choza de barro», «proponiendo
choza de barro». No verb shows its English id in a Spanish game (`propose`
was the owner's example).

## Background (checked on 0.15.160)

`render/Floaters.ts` `actionLabel` (~l. 256) returns
`t(ACTION_LABELS[action] ?? action)`; it special-cases only `craft` (recipe)
and `talk` (mode). A verb without an entry shows its id, and `t(variable)`
escapes `i18n.test.ts` (keys are read by regex). Six verbs dispatched by
`ActionSystem` have no entry in `ACTION_LABELS`: `ask_permission`,
`dress_hide`, `plant`, `propose`, `refuel_lamp`, `untie`.

## Steps

1. Test `m16-every-verb-has-a-label`: parse the `case '<id>':` lines of the
   dispatch `switch` in `ActionSystem.ts` (or, better, export the list of
   verbs if one exists) and assert each id has an `ACTION_LABELS` entry, and
   that each label has a Spanish translation.
2. Add the six labels (English + Spanish in `src/i18n/es/`).
3. Targets: extend `actionLabel(action, recipe, mode)` with an optional
   `target` description built in the sim from the person's current target
   (resource kind, item, building def). Add whole-sentence templates, one per
   verb family, e.g. `t('digging {what}', { what })`,
   `t('gathering {what}', { what })`, `t('building {what}', { what })`,
   `t('proposing {what}', { what })`. Never glue fragments (R7).
4. Test that walks the catalogue verbs with a target and checks the label is
   non-empty and contains the target's translated noun.
5. D-19: the comarca card for a coastal region says "Coast: there may be no
   reachable shore" (find the current text near "Costa" in `src/i18n/es/`).
6. `npm.cmd run i18n:soak`: no English verb left in a Spanish run.

## Done when

Both tests pass; `i18n.test.ts` passes; `i18n:soak` clean of verb ids;
screenshot of three labelled actions in Spanish.
