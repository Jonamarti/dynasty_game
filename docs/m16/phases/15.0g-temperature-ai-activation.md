## Steps

1. AI: a limited preference for a known/observed warmer shelter, only when cold
   justifies moving; respects access, relationship, reach, knowledge,
   urgencies and **places** (14.3). Minimum improvement and hysteresis so
   nobody oscillates between houses. Reuse existing actions; any new long
   action has interruption, banked progress and a visible refusal reason.
2. Run the §7 acceptance matrix of the design; resolve own regressions.
3. Activate the new mode for new games only when every route supports it;
   old saves keep legacy.
4. Measure incremental cost on a frozen benchmark (same population/map/config,
   warm-up, several repetitions): budget ≤ +5 % median `step()`; report index
   building, climate, rooms and needs separately.
5. Record limits (correspondence, growth unchanged) in `docs/bugs.md` if open.

## Done when

Matrix passes; mode on for new games; cost reported; re-pinned; screenshots.
Survival is never claimed from one seed.
