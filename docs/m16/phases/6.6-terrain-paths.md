## Goal

Owner: a ditch, like a river or a hill, affects pathfinding. People decide
whether to go round or cross; if it is too steep they may dig to level it,
which costs much more time.

## Background

`Brain.proximityBonus` measures in a straight line, so prey behind a ridge
scores as near (B17).

## Steps

1. For the best candidate of each action only (cost reasons), replace the
   straight-line distance with the path cost when an unwalkable or very steep
   tile lies between them (use the existing A* path cost).
2. Go round vs cross is decided by path cost; no separate rule.
3. If 26e shipped: a small earthwork "ramp" (one tile) that softens a slope;
   proposed when a much-used path costs more than twice the straight line.
   If 26e did not ship: only step 1–2; write the ramp as open in `bugs.md`.

## Tests

Prey behind a ditch scores lower than equally near prey in the open; a ramp
lowers the path cost.

## Done when

Tests pass; cost measured with `profile:systems` (≤ +10 %).
