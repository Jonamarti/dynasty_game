## Goal

The bottom rung of the ladder: natural shelters that exist from day one, with
no work, high warmth and limited places, claimed by whoever settles them.

## Background (checked on 0.15.160)

- Constructor order in `Simulation` (~l. 830–863): the last forks are
  `herbRng`, `ecologyRng`, `edgeRng`, `oreRng`, `ironRng`, `redOchreRng`
  (#25, ~l. 856); then `spawnResources(spawnRng)` (~l. 859),
  `spawnHerds(...)` (~l. 862), `spawnPeople(spawnRng)` (~l. 863).
- `spawnPeople` (~l. 1655) picks a camp with
  `world.randomWalkableInLargeRegion(rng, minLand)` near water. It does not
  look at buildings.
- `AGENTS.md`: `spawnResources`, `spawnHerds` and `spawnPeople` share
  **one** `spawnRng`; any draw added to it moves every person. A new kind gets
  its own appended stream.

## Design

- A cave is a `Building` with a new def `cave`: `natural: true` (new optional
  `BuildingDef` field), complete from creation, `workTicks 0`, `materials {}`,
  no `requiresTech`, not offered in the build menu, never worn by upkeep
  (14.8), not demolishable.
- `shelter 0.8` (R16); `roofed: true`; `places` = 4 for a small cave, 8 for a
  large one (size drawn from `caveRng`); footprint 2×2 or 3×3, entrance on the
  walkable side.
- **Owner:** `ownerBandId` = none at creation. Use a sentinel the code already
  understands for "nobody's" if one exists (`grep -n "ownerBandId" src/sim/entities/Building.ts`);
  if none exists, R0 before inventing one. The first band whose member sleeps
  in it claims it (the midnight sample sets the owner and emits a chronicle
  line "{band} made the cave their home"). Others may use a claimed cave only
  as they may use any building of another band today (O4 rules).

## Steps

1. Append `const caveRng = this.rng.fork();` **after `redOchreRng`** and add
   row 26 to the fork table in `AGENTS.md` in the same commit (R2).
2. Add `spawnCaves(caveRng)` and call it **after `spawnHerds` and before
   `spawnPeople`** (owner: before the people). It draws only from `caveRng`.
3. Placement: candidate tiles are walkable tiles adjacent to `rock` or
   `hills` biome (scan once at world build; this is world generation, not a
   per-tick query, so a scan is acceptable). Count = `round(rockyTiles / 2500)`
   clamped to `[0, 6]` (R16). Minimum spacing 20 tiles between caves. Same
   function for the classic island and map worlds; a map world uses a
   derived stream like the other map resources if that is the pattern there
   (check how `oreRng` is handled for map worlds and copy it).
4. Caves must not make tiles unwalkable in a way that changes
   `randomWalkableInLargeRegion`'s choices; if they do, accept it — this is a
   deliberate world change — but write it in the commit.
5. Save/load: caves are buildings, so they persist; add the round-trip test.
6. Art: a provisional cave sprite through a generator in `art/src/`
   (`art:build`, `art:sheet`); `art.test.ts` must pass.
7. Brain: no new scoring — caves are shelters with `places`, found by the
   existing shelter/sleep search (spatial hash). Check with `npm run why` that
   a band near a cave sleeps in it.
8. UI: the cave's panel shows places and owner; refusals (full, not yours) say why.

## Tests

- Determinism: same seed → same caves; the RNG table in `AGENTS.md` matches the
  constructor.
- A world with rock gets caves; a world without rock gets none.
- Spawn stream untouched: the **sequence of draws** of `spawnRng` is unchanged
  (record the first 100 values after `spawnHerds` with and without caves).
- A band camped near a cave sleeps in it within 2 nights; the cave gets its owner.
- Round trip save/load.
