## Goal

Owner notes: (N6) planned buildings should not show in the fog; something
remembered that has been seen to be gone must stop being drawn; check other
entity types. (N12) the remembered map outside the sight circle is patchy:
some parts dimmed, others black, maybe where the NPC did something.

## Background (checked on 0.15.160)

Two layers:

- `sim/social/PlaceMemory.ts` — the character's mental map, simulation state,
  saved. Updated by `Simulation.observePlaces(person)`, called only on a
  scheduled think and, for NPCs, only when not committed to an action
  (`Simulation.ts` ~l. 6790: `if (scheduledThink && (!actionCommitted ||
  person.isPlayer)) this.observePlaces(person)`). So ground walked past while
  committed may never be recorded → patchy memory (N12, first cause).
- `render/FogReveal.ts` — presentation, **only after a change of character**
  (M15 step 0 D, `e2e/fog-on-switch.spec.ts`): shows only what the new
  character has seen since the switch, "everything else black". Its header
  says: "It is not saved: a reloaded game shows the whole remembered map of
  whoever it reloads as." Cells on the rim whose centre is outside the radius
  are not revealed; when walking away, revealed cells go **fully black**
  instead of dimmed (N12, second cause).

## Steps

1. Capability tests:
   - `m16-fog-forgets-removed` (sim): a tree felled in sight and then left is
     no longer in the person's `PlaceMemory`; same for a pile taken, a building
     demolished, a herd that moved away. An unfinished site is not in the
     memory used to draw fog.
   - `m16-memory-while-walking` (sim): a person committed to a long walk
     records the tiles they pass (memory cells along the path are set).
   - `m16-fog-saved` (unit or e2e): switch character, explore, save, load →
     the same cells are revealed; switch again → cleared.
   - `m16-fog-dimmed` (renderer): a revealed cell out of sight renders dimmed,
     not black.
2. Memory while walking: observe places at least once per entered
   `PLACE_CELL_SIZE` cell for committed people too, at the cost of one call
   per cell change (not per tick). Measure the cost with `profile:systems`
   (≤ 10 % of the step; otherwise R0 and ask).
3. Forgetting: when a cell is observed, drop remembered entries for entities
   that are no longer there. Go entity class by entity class (buildings,
   trees, piles, nodes, herds) and write in the diary what each does.
4. Unfinished sites: not drawn in the fog layer (only what is complete and
   remembered).
5. Save `FogReveal`: add its grid, observer id and `active` flag to the save
   (the UI save path, wherever the renderer state that persists is serialised;
   find it from `SaveFile.ts`). Add a migration: saves without it load with
   `active = false` (today's behaviour). Round-trip test (R11, R24).
6. Dimmed, not black: a revealed cell keeps a "seen" state and renders with
   the same dim used for remembered-out-of-sight areas of the original
   character. Fix the rim cells (reveal a cell if any part of it is within the
   radius).
7. Update the header comment of `FogReveal.ts` to the new contract.
8. Screenshots: before switching, after switching and exploring, after
   reloading.

## Cierre (2026-10-20)

Las cuatro pruebas de capacidad pasan. La exploración de cada celda durante
una acción comprometida tiene su propio cursor (`placeMemoryWalkCell`), separado
del refresco estático diario para no dejar de aprender recursos visibles que
aparecen en el mismo sitio. Las observaciones eliminan únicamente recuerdos de
entidades ausentes dentro de la zona observada; el agua permanece. Guardar y
cargar conserva el observador y cada bit de `FogReveal`; v1 migra a estado
inactivo. Los cuadrados tocados por el radio se revelan y la memoria fuera de
vista queda atenuada.

## Watch out

- Never make the brain read `FogReveal`: it is presentation; the brain reads
  `PlaceMemory` (R3).
- Forgetting must happen only by seeing (`knowledge-travels-by-witness`): a
  tree felled out of sight stays remembered.
