## Goal

An expected need becomes multi-day work that is interrupted and resumed
without orders.

## Files

New `ai/Agenda.ts`; `ai/Brain.ts` (section "Building", where `site` is chosen
and `build`, `haul`, `dig`, `chop`, `gather_for_site` are scored — hooks
only, R14); `BandSystem.planBuildings` (the site-finding function);
`BandSystem.dropStaleSites`.

## Steps

1. `Purpose = { id, drive, remedy, forWhom, priority, createdDay, deadlineDay,
   siteId, state }`, plain data in `person.agenda` (round trip, R11).
2. Agenda size by age: adult 3; adolescent 1; child 0. "Adolescent" = still
   `isChild` but 12 years or older. Check in `entities/Person.ts` and
   `entities/LifeStage.ts` at what age childhood ends; if adulthood starts
   before 12, R0.
3. **Birth**, once a day, if `expected ≥ 0.25` for a drive, there is no open
   purpose for it and there is room:
   1. Pick the known remedy with the highest `value × confidence` the person
      can attempt (for a building: someone in their band knows how to raise it).
   2. If the band already has an unfinished site of that remedy, **join it**
      (add to its `backers`).
   3. Otherwise place the site as its proposer using the site-finding function
      `planBuildings` uses today — **extract it**, do not copy it. One open
      proposal per person.
   4. No known remedy → no purpose (block 8 handles that).
4. **Pull**: build actions already score only for proposer and backers. For
   sites tied to one's own purpose: comfort threshold 0.45 → 0.25, and add
   `priority × 0.6` to the score.
5. `priority = expected × remedy confidence`, recomputed daily.
6. **Resume**: nothing special; progress lives on the site (R4), the purpose
   stays and pulls again.
7. **Abandon** when `deadlineDay` passes (end of the feared season), the site
   is gone, or coverage reaches 1; on abandoning, leave `backers`.
8. `dropStaleSites`: a site with a living purpose is not stale.
9. NPC crafting half done (B7): if what is crafted belongs to a purpose, save
   progress the way ordered work already does (`person.resume`).
10. Inspector: the directed character's purposes.

## Tests (hand-built worlds, no randomness)

- A purpose is born with expected 0.5 and a known remedy.
- It joins an existing site instead of opening another.
- With hunger 90 the person eats; when hunger drops, they go back to the site
  with no order.
- A child has no agenda.
- Save/load round trip.
- `switches-off.test.ts` unchanged.
