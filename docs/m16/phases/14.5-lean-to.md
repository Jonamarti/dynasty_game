## Goal

The first real roof: a lean-to of sticks and big leaves/straw. No axe, no
mud, so it can be built anywhere, far from water. Two places, warmth between
the windbreak and the mud hut. Many are needed for a band — which is the point.

## Background

`windbreak`: 2×2, `{ sticks: 8, thatch: 4 }`, `workTicks 140`, `shelter 0.4`,
open (no `interior`), no tech. `thatch` is the existing grass/leaf item
(`Item.ts` ~l. 277). There is no separate "big leaves" item; use `thatch`
(write in the diary that thatch stands for straw and large leaves; a new item
would need its own source and is not worth it — `no-declared-but-inert`).

## Steps

1. New `BUILDINGS.lean_to` (append at the end of the table):

| Field | Starting value (R16) |
|---|---|
| size | 2×2 |
| materials | `{ sticks: 10, thatch: 8 }` |
| workTicks | 200 |
| shelter | 0.6 |
| places | 2 |
| interior | none (open on one side); but it **is a roof** for sleep/conception (step 3) |
| storage | 0 |
| requiresTech | `null` |
| description | "Sticks leant on a ridge and thatched with leaves and grass. Room for two, and warmer than a windbreak." |

2. Label and description through `t()` with Spanish («Cobertizo de ramas» or
   «Choza de ramas y hojas» — pick one, use it everywhere).
3. Roof: make `isUnderRoof` (`systems/LifeSystem.ts`) treat the lean-to's
   footprint as a roof (it has no interior; find how `isUnderRoof` handles
   open designs and add an explicit flag, e.g. `BuildingDef.roofed?: true`,
   rather than special-casing the id).
4. Art: add a generator in `art/src/` for the lean-to (construction stages and
   finished), `npm run art:build`, check `npm run art:sheet`. `art.test.ts`
   fails if a building has no art — that is your check.
5. The planner already picks "the cheapest or the best known affordable
   shelter" by reading `BuildingDef.shelter`; confirm with `npm run why` that
   bands start building lean-tos. Do not add a special rule.
