diary into that material.

1. From `docs/m16/diary.md`, write `docs/m16/history.md`: one section per

3. Update `docs/next-steps.md` with what M16 leaves for M17 (including the
   deferred item weight and game modes). If you think the game could leave
   alpha, say it there — **do not** touch the version label.

## Done when
