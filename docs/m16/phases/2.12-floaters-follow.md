## Goal

A floating text attached to a moving person or animal moves with it.

## Steps

1. In `render/Floaters.ts`, add an optional `followId` (person or animal id)
   to a floater. When set, each frame position = entity position + the
   floater's own rise offset; if the entity is gone, the floater stays where
   it was last.
2. Set `followId` where floaters are created for a person/animal.
3. Renderer unit test: a floater with `followId` whose entity moves 5 tiles is
   drawn 5 tiles away.

## Done when

Test passes; short screenshot sequence of a label following a walker.
