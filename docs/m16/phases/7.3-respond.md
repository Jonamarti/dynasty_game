## Goal

The believed gap feeds deciders that **already exist**. No new decider.

| Response | Existing decider | What it receives |
|---|---|---|
| arm | object purpose (6.2) with remedy `protect` | strength gap |
| fortify | earthwork site proposal (5.3) | strength gap; answers B3 |
| copy | `examine` (6.4), asking, marrying out | technique gap |
| ally or make peace | `considerStance` | strength gap against a third band |
| submit | `considerSubmission` | the strength **believed** by the chief instead of the real one |
| strike first | `considerRaid` | small and growing gap; aggressiveness |
| leave | `considerRelocation` | chronic fear, which it already reads |

## Steps

1. `response(chief, otherBand)` in `Rivalry.ts`: a weight per response from
   the gaps, the current relation and the band temperament (7.4).
2. Each decider reads its weight, only with the switch on.
3. A counter per chosen response.

## Tests

A believed strong rival raises `fortify`/`arm` weights; a believed weak one
raises `strike first` for an aggressive chief; `submit` follows belief, not truth.

## Done when

Tests pass; R13 holds.
