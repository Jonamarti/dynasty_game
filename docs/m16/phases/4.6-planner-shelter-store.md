## Goal

With foresight on, shelters, hearths and stores are born only from purposes.
The rest of the planner **stays** until 6.7.

## Background

What `BandSystem.planBuildings` asks for today (check the `wanted =` branches):

| Branch | Replaced by | Phase |
|---|---|---|
| shelter (cheapest or best) | `warmth` purpose | 4.6 |
| hearth | `warmth` purpose (remedy `building:hearth`) | 4.6 |
| store or granary | `hunger` purpose | 4.6 |
| workshops/stations | object purpose | 6.7 |
| compost heap, field, trap, pen, well | production purpose | 6.7 |

## Steps

1. With the switch on, skip the first three branches.
2. Keep proposer assignment for ownerless sites and stale-site retirement.
3. `MAX_SITES` (2, `BandSystem.ts` ~l. 336) and any per-member structure cap
   stop applying to purpose-born sites: coverage limits them (and upkeep, 14.8).
4. New test `every-design-has-a-proposer`: walk `BUILDINGS`; each design must
   be requested by a live planner branch **or** be a learnable remedy of some
   drive (4.2), or be `natural`/`furniture`. Fail naming any orphan.

## Tests

The test above; a band with remembered cold and no planner raises a lean-to;
a band with no memory raises nothing.

## Done when

Tests pass; R13 holds.

## Watch out

`bands-dont-overbuild`, `building-starts-small`, `projects-find-backers`,
`shelter-answers-cold` will move with the switch on. Read what they measure
before calling them broken (R18).
