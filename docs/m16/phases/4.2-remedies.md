## Goal

People know what relieves each need because they lived it, saw it, or were
told — never from a hand-written table.

## Files

`ai/Lessons.ts`; `systems/NeedsSystem.ts` (where effective shelter is computed
and `warm:hearth` is written to `Beliefs`); `systems/KnowledgeSystem.ts`
(`tryObserve`); `social/Conversation.ts`.

## Steps

1. `Lessons.remedy[drive][remedyId] = { value, confidence, source, day }`.
   Ids built from data: `building:<defId>`, `item:<itemId>`, `practice:<techId>`.
2. **Lived** (confidence +0.25 per occurrence, cap 1):
   - warmth: in `NeedsSystem`, where effective shelter is computed, when the
     person is cold and under a building with shelter (and has a place, 14.3):
     record `warmth` / `building:<id>` with value = that shelter. Same for a
     garment worn. Leave the existing `warm:hearth` belief alone.
   - hunger: taking food from a store while hungry: `hunger` / `building:<id>`.
3. **Seen** (+0.1): someone with cold > 50 who sees another under a roof with
   less cold learns that remedy — in the same place where seeing someone eat
   teaches today (`tryObserve`).
4. **Told** (+0.05): in the long conversations that already pass food news,
   pass the speaker's highest-confidence remedy; also pass season lore (B21).
5. Forgetting: confidence −0.1 per year without reinforcement.
6. Save/load: plain data inside `Lessons` (round trip, R11).

## Tests

- Sleeping cold under a lean-to teaches `building:lean_to`.
- Only seeing it teaches it with lower confidence.
- No hand-written remedy list exists: a test walks `BUILDINGS` and checks that
  every design with `shelter > 0` can be learnt as a warmth remedy.

## Done when

Tests pass; R13 (behaviour identical with the switch off).
