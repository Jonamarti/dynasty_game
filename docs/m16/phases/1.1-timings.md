# M16 1.1 — Measure how long everything takes

| | |
|---|---|
| Stage / step | 1 / 4 |
| Switch | none |
| Changes the world | no |
| Depends on | 0.3 |

## Goal

A table of what the verification costs, slowest first, so that 1.5–1.7 attack
the right things.

## Steps

1. For every key of `SCENARIOS` in `tools/simcheck.ts`, run it alone:
   `npm.cmd run sim:check -- --scenario <name>` and record seconds and steps
   per second (the report prints both). Skip nothing; note the `slow: true` ones.
2. Time `npm.cmd test -- --maxWorkers=1 --testTimeout=15000` and the five
   slowest test files (vitest prints per-file durations).
3. Time `npm.cmd run e2e` and the five slowest specs.
4. Write `docs/m16/timings.md`: machine, date, commit; one table per tool,
   slowest first; and a closing paragraph naming the **three** biggest costs.

## Done when

`docs/m16/timings.md` exists and names the three biggest costs.

## Watch out

Nothing else may run on the machine meanwhile (R27). Docs-only, no version bump.
