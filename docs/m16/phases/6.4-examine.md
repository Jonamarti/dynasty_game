# M16 6.4 — Examining an unknown object (N11)

| | |
|---|---|
| Stage / step | 10 / 109 |
| Switch | `experiment` |
| Changes the world | only with the switch on |
| Depends on | 8.1, 6.2 |
| Triage | N11 (second half) |

## Goal

Owner: those who do not know what an object is investigate it and reverse
engineer it little by little; also objects made by another tribe.

## Files

`knowledge/Synthesis.ts` (`Idea`), `systems/KnowledgeSystem.ts`.

## Steps

1. Action `examine` on a visible object, loose or worn by someone.
2. Chosen by someone who does not know the object's tech, is curious
   (`curiosityNeed`) and has immediate needs covered. 40 ticks, interruptible.
3. Effect:
   - prerequisites of the tech met: create or advance an `Idea` with
     `insight +0.15` and the story "examined a <object>". Examining alone never
     takes it past 0.6; the rest needs a prototype, as always;
   - prerequisites not met: no tech; they only learn what it is for if they
     have seen it used (6.2 remedies).
4. Once per person, object kind and day. Same for objects of other bands.

## Tests

Three examinations take insight to 0.45; a fourth the same day does not count;
without prerequisites, nothing.

## Done when

Tests pass; R13 holds.
