## Goal

After choosing a building in the build menu, the player can rotate it before
placing it.

## Files

`world/HouseInterior.ts` (`houseForFootprint`, `houseInteriorTiles`),
`entities/Building.ts` (`interiorDoorSide` already exists:
`'north' | 'east' | 'south' | 'west' | null`), build cursor in `main.ts`/`ui`.

## Steps

1. A rotate key (R) and button cycle the orientation; non-square footprints
   swap width/height.
2. The footprint and the real interior respect the orientation; the door side
   follows it. Store the orientation on the building (saved, R11).
3. NPC placement keeps today's default orientation.
4. Art: if sprites are directional, the generator must produce each needed
   orientation (`art/src/`, `art:build`); if not, R0 and rotate only the door.

## Tests

A rotated building has rotated footprint and door; save/load round trip.

## Done when

Tests pass; screenshots of the four orientations.
