## Goal

The player can tell which shore tiles can be dug for mud; on any other tile
the menu says why not.

## Steps

1. Find the predicate that decides "mud here" (`Earth.isWetSubsoil` and the
   dig-mud catalogue entry in `ActionCatalog.ts`).
2. Renderer: a subtle marker (texture/tint) on tiles where that predicate is
   true and the player knows mud (or always — say which in the diary).
3. Menu: on a tile where digging mud is not possible, the entry is disabled
   with the reason ("No wet ground here", "Too far from water"), through `t()`.
4. Test `m16-mud-shore-markers`: the renderer marks exactly the tiles where the
   predicate is true (renderer test with fake context); the menu text exists.

## Done when

Test passes; screenshot of a river bank with markers.
