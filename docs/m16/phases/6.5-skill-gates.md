## Goal

Owner: a low building skill lets you raise stores and windbreaks but not
houses, so people must practise first; some start more gifted, so division of
labour emerges from talent and practice.

## Files

`entities/Building.ts` (`BuildingDef`), `entities/Recipe.ts`,
`entities/Person.ts` (`skills`, 0–100).

## Steps

1. Optional `minSkill` on buildings and recipes, on the skill they already use.
2. Starting values (R16), reflecting the new shelter ladder:

| Thing | Min skill |
|---|---|
| windbreak, lean-to, storage pit, hearth, trap | 0 |
| mud hut | 10 |
| wattle hut, granary | 25 |
| longhouse | 35 |
| others | decide per item, write the table in the diary |

3. Rule: a site advances only if someone **working on it at that moment** has
   the level (D-2). Others work at their own rate and gain skill.
4. If nobody in the band has the level, nobody proposes it; if the player
   places it, the cursor says so (R6).
5. Guard tests:
   - `every-gate-is-reachable`: for each thing with min > 0 there is another
     with min 0 that trains the same skill;
   - in a fresh world every founder can make every min-0 thing.
6. Counter `site_waiting_master`.

## Tests

The guard tests; a site with no master present does not progress; with one,
it does and helpers gain skill.

## Done when

Tests pass; counter reported. Note B20 (a band that loses its builders does
not recover): report the share of sites waiting for a master in `band`.
