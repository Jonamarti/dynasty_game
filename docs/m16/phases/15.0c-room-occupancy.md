## Goal

One temperature per complete, non-ruined building with an interior, warmed by
the living people inside, with inertia.

## Files

New `src/sim/core/RoomTemperature.ts`; reuse `world/HouseInterior.ts`
(`houseInteriorContains`) and 14.3's occupancy count (one way of counting
who is inside — do not write a second).

## Steps

1. State per building: `roomCelsius`, `lastTick`. A newly completed house
   starts at the outdoor temperature.
2. Advance (pure helper):
   ```
   base       = gainPerOccupant × occupantEquivalents / relativeVolume
   bounded    = min(base × retention, maxBodyGain)
   body       = min(bounded, max(0, comfortTarget − outside))
   target     = outside + body + fireGain
   next       = target + (current − target) × exp(−dt / tau)
   ```
   Starting values (R16): `maxBodyGain` +4 °C, `comfortTarget` 18 °C, `tau`
   0.08 days (convert with `ticksPerDay`). Adult 1, child 0.5, baby 0.25
   equivalents (shared age categories). Relative volume from the real interior
   area normalised to the reference hut.
3. Occupancy through the spatial hash (R5); all bands; living and present; a
   carried baby once, at the carrier. Not the dead, not absent travellers, not
   bed reservations.
4. One shared update per tick, **independent of person order**.
5. Windbreaks, lean-tos, stations, open stores, unfinished sites: no room
   temperature. A ruin has none; repairing restarts from outdoor.

## Tests (`room-temperature.test.ts`)

4 adults > 1 > 0 in gain; door/wall/margin/outside do not count; inertia (no
jump on entering, gradual fall on leaving); bigger house warms less; body gain
≤ max; reversing the person order changes nothing. Make each test fail with
the mechanism broken (design §7 negatives) before trusting it (R17).
