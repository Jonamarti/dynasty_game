## Goal

Owner: separate the tribe view from other tribes; a separate view shows the
relations between bands instead of putting every NPC in the tribe view.

## Steps

1. The tribe view (`ui/TribeTree.ts` / `TribeGraph`) shows only the player's band.
2. New view "Other bands": one node per band the player's character knows,
   edges with the relation (stance, temperament label of 7.4, believed gaps
   of 7.2 from the player's own beliefs).
3. Everything through `social/Knowledge.ts` (R8): an unknown stranger does not
   appear; a known stranger's sheet does not reveal skills.
4. R10 for the overlay; digest redraw.

## Tests
