## Goal

Every test or check that was red at the baseline has a written verdict: **the
premise changed** (rewrite it, R18) or **the world is wrong** (record the
mechanism in `docs/bugs.md`). None is "fixed" by moving a threshold.

## Background

At 13-10 the known reds were: `compact-correspondence` (thirst 16.90 > 15),
`determinism` (counter `compact_food_nutrition_gather` = 0),
`people-knowledge` (spread 0.70 > 0.60), `polity` (tribute 0; the coup leaves
`chiefId` 2), `salters-checks` (expected 0, got 1); and in the `band` check:
`cravings-steer-the-diet`, `moods-move-choices`, `perf-budget`,
`hills-see-farther`. The M15 close reports the unit suite green at
`0.15.160`, so some are gone — **use the list frozen in `docs/m16/baseline.md`**
(phase 0.1), not this one.

## Steps

For each red test/check of the baseline, `polity` and `determinism` first
(their failure is a counter or one case, not a rate):

1. Run it alone; read what it measures (the code, not the name).
2. `git log -S '<threshold or identifier>'` to find when and why it went red.
3. Verdict in the diary: premise changed / world wrong / chaos — with evidence
   (3 runs, counter values).
4. Premise changed → rewrite the test to measure what it was meant to; say so
   in the commit. World wrong → `docs/bugs.md` entry with the mechanism; leave
   the test red and listed in the baseline.

## Done when

Each baseline red has a verdict line in the diary and, where applicable, a
`bugs.md` entry or a rewritten test.

## Watch out

**Never** relax a threshold (`AGENTS.md`, R18). `people-knowledge` in
particular is answered by 16.4 (historical materials), which the owner asked
for instead of touching diffusion rates.
