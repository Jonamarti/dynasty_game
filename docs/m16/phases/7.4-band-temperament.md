# M16 7.4 — Band temperament drifts (B12)

| | |
|---|---|
| Stage / step | 9 / 98 |
| Switch | `rivalry` |
| Changes the world | only with the switch on |
| Depends on | 7.3 |
| Triage | B12 ("A people's culture never changes") |

## Steps

1. `Band.strangerRegard` is drawn at founding (`cultureRng`) and never moves.
   With the switch on, each day it moves 2 % toward a target: mean of members'
   traits, chief's traits counting double, and experience (raid suffered:
   down; marriage or trade with strangers: up).
2. A label for the panel, computed not saved: aggressive, defensive, trader or
   independent, by thresholds on the regard and the responses chosen in the
   last year.

## Tests

Repeated raids lower the regard; marriages raise it; the label follows.

## Done when

Tests pass; R13 holds.
