## Goal

Owner rule: replicate how the first humans did it. More materials (kinds of
stone, clay, papyrus…), and prototypes of `TECHS` reviewed by that rule —
**instead of touching diffusion rates** (the fix the owner asked for in place
of loosening `people-knowledge`, E12).

## Steps

1. Walk the prototypes in `TECHS` and write, per tech, the material the first
   humans used according to the node's source (`firstKnown`), in a table in
   the diary.
2. Where it does not match, propose the right material in that table **before
   changing anything**, and stop for the owner's approval (R0: write the
   question in `doubts.md`; continue with other phases meanwhile).
3. Once approved: add only the materials some approved prototype uses, each
   with a map source (own appended stream if it is a new resource kind —
   `AGENTS.md` spawn rule) and a consumer.
4. Start with `writing`: today it needs `flint`, and only 4 of 959 regions
   have both cereal and flint, which blocks the State branch. Clay tablets are
   the historical answer.

## Tests

`every-gate-is-reachable`; every new material has a consumer and a source.

## Done when

Approved table applied; tests pass; re-pinned.
